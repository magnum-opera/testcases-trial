# dev-loop profile

## Branch template

`feat/{issue}`, sub-lanes `feat/{issue}-{area}`

## PR title format

`<type>(<scope>): #<issue> - <title>`. One exception: a Ticket whose title starts `test(e2e): #<PRD> - ` gives its pull request its own title, as it is, because QA: Review finds a PRD's end-to-end pull request by that title.

## Constraints

None.
